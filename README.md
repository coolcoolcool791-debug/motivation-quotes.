# Ninja Eclipse: Shadow Trials

A lightweight single-player offline 2.5D-style action-adventure game prototype for mobile/PC browsers.

## Features

- Character selection with two ninja heroes and skill icons.
- Real-time combat with sword attack, special abilities, and stealth mode.
- Enemy waves (monsters and rival warriors) with increasing level difficulty.
- Upgrade system (speed, attack, special power).
- Dark fantasy interface with glowing buttons and colorful effects (fire, lightning-inspired bursts, shadow effects).

## Run

Open `index.html` in a browser or run a static server:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Controls

- Move: `WASD` or Arrow keys
- Attack: `J` or Left click
- Special ability: `Space` or `K`
- Toggle stealth: `L`
